# myhome_tbilisi

Бот стежить за пошуком на myhome.ge (оренда квартир у **Тбілісі**, лише власники) і шле **нові**
оголошення в Telegram-групу: фото, ціна, район, телефон, позначки «агент чи власник». Уся
логіка — в одному файлі `watcher.py`. Мова коду, коментарів і повідомлень — українська.

## Близнюки: myhome-watcher (Батумі) і ssge-watcher (ss.ge)

Це окремий проєкт зі своїм репозиторієм, базою `state.json`, секретами й будильником, але код —
копія **myhome-watcher** (той самий бот для Батумі, github.com/romario00724-glitch/myhome-watcher).
Є ще **ssge-watcher** — такий самий бот для ss.ge (локально ~/Desktop/Скрапери/ssge-watcher);
цю папку теж тримати там: ~/Desktop/Скрапери/myhome_tbilisi.

Користувач хоче, щоб боти працювали **один в один**: змінюєш спільну частину тут (Telegram,
вигляд повідомлення, позначки, `state.json`, workflow) — спитай, чи повторити в myhome-watcher
і ssge-watcher, і навпаки.

Чим цей репозиторій відрізняється від myhome-watcher — і тільки цим (при перенесенні змін
звідти ці місця не затирати):
- `searches.txt` — пошук по Тбілісі: `cities=1` (у Батумі `cities=15`), підпис «Оренда Тбілісі»;
- `watcher.py` — два рядки з назвою міста: підказка в `search_params` («Оберіть на сайті
  Тбілісі») і `TRANSLATE_PROMPT` («…в Тбилиси»); решта файлу байт у байт як у Батумі;
- `watch.yml` — `name:` і `concurrency.group` = `myhome_tbilisi`;
- README і цей файл.

## Як запускається

```
cron-job.org ──► workflow_dispatch ──► GitHub Actions: python watcher.py --once
 кожні 10 хв                            один прохід по myhome.ge (нові оголошення → група), ~25 с
```

- **Будильник — cron-job.org**, завдання `myhome_tbilisi` (копія завдання `myhome-watcher`, інший
  лише URL). Розклад GitHub (`schedule:` у `watch.yml`) спрацьовує ~раз на 2,5 год, тому він лише
  запасний. Токен будильника спільний для всіх трьох ботів (fine-grained, `Actions: Read and
  write`), **спливає 28.09.2027** — тоді всі три тихо замовкнуть, прийде лист від cron-job.org.
  Деталі й коди помилок — README, розділ «Хто насправді запускає бота».
- **На myhome.ge бот ходить лише під час запуску**: кілька сторінок видачі + картка кожного
  нового оголошення. Між запусками нічого не працює.
- Запуски йдуть строго по одному (`concurrency`). Checkout бере `ref: ${{ github.ref_name }}`,
  щоб запуск із черги не працював зі старим `state.json`.
- Після запуску workflow комітить `state.json` у `main` (`state: update [skip ci]`) — тому
  локальний `main` постійно відстає: перед роботою `git pull`.
- Перший запуск із новим рядком у `searches.txt` нічого не шле в групу, а тихо запам'ятовує
  поточні оголошення й пише «✅ Стежу за пошуком…».

## Секрети й налаштування

GitHub → Settings → Secrets and variables → Actions (секрети **цього** репозиторію, не Батумі):

| Назва | Що це |
|---|---|
| `TELEGRAM_BOT_TOKEN` (secret) | токен бота. Він же ключ HMAC для відбитків телефонів у `state.json` (`phone_fingerprint`): заміна токена = лічильник «телефон уже траплявся» почне рахувати заново |
| `TELEGRAM_CHAT_ID` (secret) | група, куди йдуть оголошення з Тбілісі |
| `OPENAI_API_KEY` (secret) | переклад російською грузинських/англійських описів і адрес. Без нього — просто без перекладу. У Тбілісі оголошень більше й частіше грузинською, тож і витрат на OpenAI більше, ніж у Батумі |
| `OPENAI_MODEL` (variable) | необов'язкова; за замовчуванням `gpt-5-mini` |

Локально — `telegram.json` у корені (`token`, `chat_id`, `openai_key`), у `.gitignore`.
Репозиторій **публічний**: жодних ключів у коді й комітах.

## Спадок від Батумі — не чистити

Кнопки «📢 Додати в канал» тут ніколи не було. Рядок у `load_state`, що викидає записи
`tg_offset` / `posted` / `facts`, — її залишок із myhome-watcher; хай лишається, щоб `watcher.py`
збігався з батумським.

## Правила роботи з кодом

- **Не запускати `python watcher.py` на комп'ютері паралельно з GitHub** — у двох копій різні
  `state.json`, і ті самі оголошення прийдуть у групу двічі.
- **`import watcher` + наявний `telegram.json` = реальні повідомлення** в групу. У тестах
  глушити `tg_call`, `tg_upload`, `download_image`, `_post_json` (OpenAI) і `save_state` (або
  підмінити `STATE_FILE`).
- Користувач не програміст: пояснювати простими словами, українською.
