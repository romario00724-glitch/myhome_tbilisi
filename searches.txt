# Посилання на пошук з myhome.ge — по одному на рядок.
#
# Як отримати посилання:
#   1) відкрийте myhome.ge і оберіть: Аренда (For rent) або Продажа (For sale) → Квартира → Тбилиси;
#   2) за бажанням задайте район, ціну, кількість кімнат; увімкніть «Собственник» (Owner);
#   3) натисніть «Поиск» і скопіюйте адресу з адресного рядка браузера.
# У правильному посиланні є «?deal_types=...» і «cities=...».
# Фільтр «Власник» скрипт додає сам, навіть якщо ви забули його увімкнути.
#
# deal_types: 2 — оренда, 1 — продаж; real_estate_types: 1 — квартира, 2 — приватний будинок,
# 5 — комерція. Ціна «від» — currency_id=2&price_from=... (у доларах).
# Зараз оренда: квартири від $350, будинки від $1000, комерція від $600. Продаж (квартири без
# порогу, будинки від $100 000, комерція від $50 000) з 27.10.2026 вимкнено — див. нижче.
#
# Перед посиланням можна написати назву і « | » — вона буде видна в повідомленні
# (група читає російською, тож і назва російською).
#
# Після посилання можна дописати « | » і назву іншої групи латиницею — тоді пошук іде в чати з
# секрету GitHub TELEGRAM_CHAT_ID_<НАЗВА>, а не в основну групу (TELEGRAM_CHAT_ID). «sale» — група
# продажу «ss/myhome (Продажа)», секрет TELEGRAM_CHAT_ID_SALE (локально — "chat_id_sale" у
# telegram.json). Кілька чатів — через кому. Поки секрету немає, бот такий пошук пропускає.
#
# З 21.10.2026 myhome.ge показує гостям лише 5 сторінок видачі (120 оголошень), а платні (VIP)
# оголошення завжди стоять першими. Якщо платних у пошуку набирається під 120, бот не бачить
# звичайних, тому такий пошук ділиться на кілька рядків з однаковою назвою за ціною
# (price_from / price_to, межі включні: сусідні діапазони стикуються, наприклад ...price_to=80000 і
# ...price_from=80000). Коли діапазон переповнюється, у журналі запуску з'являється «...лише N
# звичайних оголошень... поділіть цей пошук за ціною дрібніше» — тоді розділити його ще надвоє.
#
# Приклад рядка:
# Оренда | https://www.myhome.ge/ru/...?deal_types=2&real_estate_types=1&cities=...&owner_type=physical
